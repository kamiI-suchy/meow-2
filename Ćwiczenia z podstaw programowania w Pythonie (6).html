Ćwiczenie 1

Ćwiczenie polega na utworzeniu animacji trzech piłek, które odbijają się od krawędzi okna o rozmiarze 640 x 480 pikseli. Poniżej tabela z danymi (rozmiar, pozycja początkowa, prędkość) i grafikami piłek do pobrania:

Nazwa (link) ball_soccer.png ball_volleyball.png ball_basketball.png
Grafika
Rozmiar grafiki (px) 100 x 100 90 x 90 120 x 120
Pozycja początkowa x: 0, y: 0 x: 100, y: 200 x: 200, y: 50
Prędkość dx: 5, dy: 5 dx: -4, dy: 4 dx: 8, dy: -8
Zadanie można napisać w oparciu o przykład kodu dla prostej animacji jednej piłki (bez odbijania od krawędzi): 
import pygame
import sys

pygame.init()
fpsClock = pygame.time.Clock()
screen = pygame.display.set_mode((640, 480))
ball = pygame.image.load("ball_soccer.png")
rect = ball.get_rect()

while True:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            sys.exit()

    rect = rect.move([5, 5])
    screen.fill((100, 100, 100))
    screen.blit(ball, rect)
    pygame.display.update()
    fpsClock.tick(50)
Zadanie należy wykonać z wykorzystaniem klas:
  • Ball: zawiera właściwości związane z daną piłką oraz metodę update() odpowiedzialną za zmianę pozycji piłki na ekranie
  • Game: zawiera właściwości i metody związane z ekranem (inicjowanie, odświeżanie) oraz dodawaniem piłek do listy (potrzebne przy odświeżaniu ekranu)
Uruchomienie poniższego kodu powinno wykonać animację trzech piłek odbijających się od krawędzi okna: 
game = Game()
game.addBall(Ball("ball_soccer.png", [0, 0], [5, 5]))
game.addBall(Ball("ball_basketball.png", [100, 200], [-4, 4]))
game.addBall(Ball("ball_volleyball.png", [200, 50], [8, -8]))
game.start()
